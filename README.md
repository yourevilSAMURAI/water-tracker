# Water Tracker | Cold Wave

Интерактивный SPA-трекер воды с сохранением истории. Мой третий проект в портфолио, созданный для отработки навыков работы с датами, состоянием (State Management) и локальным хранилищем браузера.

## Посмотреть вживую:
Вы можете открыть трекер по ссылке:
**[Открыть Water Tracker](https://yourevilsamurai.github.io/water-tracker/)**

## Что умеет проект:
*   **Отслеживание воды**: Быстрое добавление (200, 250, 500 мл) или ввод своего объёма (до 3000 мл).
*   **Умный прогресс-бар**: Круговой SVG-индикатор, который заполняется по мере приближения к цели.
*   **Календарь и история**: Визуальный календарь на текущий месяц с мини-стаканами, показывающими прогресс за каждый день.
*   **Дневной журнал**: Точное время каждой записи. Возможность отменить последний шаг.
*   **Защита данных**: Безопасная загрузка из `localStorage` (защита от сбоев и повреждения данных).
*   **Предупреждение о переизбытке**: Если выпить больше 115% от нормы, появляется информативное модальное окно (показывается один раз в день).
*   **Две темы**: Светлая (Cold Wave) и тёмная (Dark Wave) с сохранением выбора пользователя.
*   **Адаптивность**: Полностью рабочий интерфейс на смартфонах и планшетах.

## Технологии и чему я научился:
*   **HTML5** (включая SVG для кругового прогресса).
*   **CSS3** (CSS-переменные для тем, Grid, Flexbox, анимации, `calc()` для адаптивности).
*   **JavaScript (Vanilla)**:
    *   Управление сложным состоянием (объект с датами и массивами записей).
    *   Работа с **датами** (`Date`, `toLocaleTimeString`, проверка наступления нового дня).
    *   Работа с **`localStorage`** и обработка исключений (`try/catch`).
    *   Динамическое создание DOM-элементов.
    *   Обработка событий клавиатуры (`Enter` для отправки, `Esc` для закрытия).

## Структура проекта:
*   `index.html` — разметка интерфейса и модальных окон.
*   `style.css` — дизайн, темы и адаптивность.
*   `script.js` — вся логика трекера и работа с хранилищем.
