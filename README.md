# Water Tracker | Cold Wave (Telegram Mini App)

Полноценное Full-stack приложение (Telegram Mini App) для отслеживания водного баланса. Проект эволюционировал от простого SPA-сайта с локальным хранилищем до безопасного веб-приложения с облачной базой данных, серверной валидацией и защитой от спама.

## Посмотреть вживую:
Приложение интегрировано в Telegram и доступно по ссылке (через бота):
**[Открыть Water Tracker](https://water-tracker-main.layero.app/)** *(ссылка на Layero)*

## Технологический стек:
**Frontend (Клиент)**
*   HTML5 / CSS3 — адаптивная верстка, CSS-переменные для тем (Cold Wave / Dark Wave).
*   Vanilla JavaScript (ES6+) — управление состоянием, работа с DOM, `fetch` API.
*   Telegram WebApp API (интеграция с интерфейсом Телеграма `tg.ready()`, `tg.expand()`).
*   Асинхронный State Management (защита от Race Condition).
**Backend (Сервер)**
*   Node.js + Express.js. — обработка API-запросов, раздача статики.
*   `crypto` (Node.js) — для криптографической проверки подписи данных от Telegram (HMAC-SHA256).
**База данных:**
*   **Turso** (Serverless SQLite / libSQL).
*   Клиент `@libsql/client`.
**Деплой и Инфраструктура:**
*   **Layero** — хостинг Node.js-сервера и статики.
*   Переменные окружения (`.env`) для безопасного хранения секретов.

## Ключевые возможности и фичи:
*   **Синхронизация в облаке:** Данные больше не теряются при очистке кэша или перезапуске сервера. Вся история хранится в Turso DB.
*   **Безопасность (Anti-IDOR):** Сервер не доверяет клиенту. Каждый запрос проверяется через расшифровку `initData` от Telegram (HMAC-подпись). Подделать ID пользователя невозможно.
*   **Защита от "Race Condition" (лагов):** Внедрен механизм `isSending` и визуальная блокировка кнопок. Исключены дублирующие запросы при быстром клике.
*   **Умный прогресс-бар:** Плавный круговой SVG-индикатор выполнения дневной нормы.
*   **Календарь и Журнал:** Визуализация прогресса за каждый день (мини-стаканы) и точный журнал выпитой воды с возможностью отмены последнего действия.
*   **Сброс данных:** Реальная очистка истории в базе данных (ранее был только локальный сброс).
*   **Оптимизация запросов:** Сервер отдает историю только за последние 60 дней, что предотвращает зависание интерфейса при росте базы данных.
*   **UX/UI:** Две темы (Cold Wave / Dark Wave), адаптивная верстка, предупреждение о гипергидратации (водной интоксикации).

## Архитектура и Безопасность:
1.  **Клиент (Браузер/Telegram):** При загрузке страницы Telegram WebApp API передает объект `initData` (паспорт пользователя с подписью).
2.  **Запрос:** Фронтенд отправляет `fetch` запрос, прикрепляя `initData` в заголовок `X-Telegram-Init-Data`.
3.  **Сервер (Мидлвар):** Express перехватывает запрос, берет `TELEGRAM_BOT_TOKEN` из переменных окружения и с помощью модуля `crypto` проверяет подпись. Если подпись верна — сервер извлекает настоящий `user.id` и пропускает запрос дальше. Если нет — возвращает `403 Forbidden`.
4.  **База данных:** Сервер делает запрос к Turso, используя только проверенный ID.

## Локальный запуск:
1. Клонируйте репозиторий: `git clone https://github.com/yourevilSAMURAI/water-tracker.git`
2. Установите зависимости: `npm install`
3. Создайте файл `.env` в корне проекта и добавьте ключи:
   ```env
   PORT=3000
   TURSO_DATABASE_URL=your_turso_db_url
   TURSO_AUTH_TOKEN=your_turso_token
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token
   ```
   *(Внимание: Никогда не выкладывайте файл `.env` на GitHub!)*
4. Запустите сервер: `npm start`
5. Откройте `http://localhost:3000` в браузере
