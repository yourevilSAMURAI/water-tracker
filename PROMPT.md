# Промпт для создания Water Tracker (v1.0)

Этот файл содержит детальный промпт, с помощью которого можно сгенерировать аналогичный проект.

## Основной Промпт:

> **Роль:** Ты — Senior Frontend-разработчик и эксперт по UI/UX дизайну.
> 
> **Задача:** Напиши код для одностраничного веб-приложения (SPA) — трекера воды. Используй чистый HTML, CSS и Vanilla JavaScript. Код должен быть разделен на три файла: `index.html`, `style.css` и `script.js`.
> 
> **Общий стиль (Дизайн):**
> *   Минимализм. Светлая тема — "Cold Wave" (пастельно-голубой фон, белые карточки, черные контуры, шрифт Montserrat).
> *   Темная тема — "Dark Wave" (глубокий черный фон, темно-серые карточки, акцентный красный цвет).
> *   Использовать CSS-переменные (`:root` и `[data-theme="dark"]`) для переключения тем.
> 
> **Функционал:**
> 1.  **Главный экран:** Круговой SVG-прогресс-бар, показывающий выпитое количество относительно цели (по умолчанию 2000 мл).
> 2.  **Добавление воды:** Кнопки быстрого выбора (+200, +250, +500 мл) и поле для ввода своего объёма (с валидацией от 1 до 3000).
> 3.  **Отмена:** Кнопка «Отменить шаг», которая удаляет последнюю запись за выбранный день.
> 4.  **Календарь (в правой панели):** Сетка дней текущего месяца. Каждый день имеет мини-иконку стакана, заполненного пропорционально выпитой воде. Будущие дни заблокированы.
> 5.  **Журнал (в правой панели):** При клике на день в календаре открывается список записей с точным временем (например, "14:30 — 250 мл").
> 6.  **Левая панель:** Текст «О нормах» (о пользе и вреде воды, расчет нормы).
> 7.  **Предупреждение:** Если выпить больше 115% от цели, показать модальное окно с предупреждением (показывать один раз в день).
> 8.  **Тема:** Кнопка переключения тем.
> 
> **Дополнительные требования:**
> *   Данные сохранять в `localStorage` (история по дням).
> *   Использовать безопасный `JSON.parse` с `try/catch` на случай повреждения данных.
> *   Реализовать проверку наступления нового дня (чтобы приложение не писало вчерашние данные в сегодняшние).
> *   Добавить поддержку клавиш `Enter` (для добавления) и `Escape` (для закрытия панелей и модалок).
> *   Адаптивность: на мобильных устройствах панели должны быть не шире экрана (`max-width: calc(100vw - 40px)`).
